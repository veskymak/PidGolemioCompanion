# PidGolemioCompanion

PidGolemioCompanion is an Android app for viewing Prague Integrated Transport (PID) data from Golemio.

- Build system and dependency manager: Gradle, using the repository's wrapper (`.\gradlew.bat` on Windows).
- For build and validation commands, see [Build and validation](docs/agent-guides/build-validation.md).
- When changing an API, map-tile, or routing integration, consult the [API integration docs](docs/api/README.md).
