# PidGolemioCompanion
## 🔑 Získání a nastavení Golemio API klíče

Aplikace pro načítání dat o spojích a zastávkách PID vyžaduje přístup k datové platformě **Golemio API**. Získání API klíče je zcela zdarma a zabere jen pár minut.

### 1. Jak získat API klíč:

1. Přejdi na portál pro správu klíčů na [api.golemio.cz/api-keys](https://api.golemio.cz/api-keys).
2. Zaregistruj se pomocí svého e-mailu (nebo se přihlas, pokud již účet máš).
3. Ověř svou e-mailovou adresu kliknutím na odkaz, který ti dorazí do schránky.
4. Po přihlášení klikni na možnost vytvořit nový klíč (**Generate token** / **Add key**).
5. Klíč si pojmenuj (např. `PidGolemioCompanion`) a potvrď.
6. Vygenerovaný API klíč si **zkopíruj**.

### 2. Vložení klíče do aplikace:

1. Otevři aplikaci **PidGolemioCompanion**.
2. V menu přejdi do sekce **Laboratoř**.
3. Do příslušného pole vlož zkopírovaný API klíč a ulož.

> ⚠️ **Upozornění:** Svůj API klíč nikdy nesdílej veřejně ani ho necommituj do repozitáře.
>
